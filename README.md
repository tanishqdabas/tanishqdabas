## Portfolio — the app

[**tanishqdabas.vercel.app**](https://tanishqdabas.vercel.app) is my portfolio web app — the site hosting my work. It's an interactive, animation-driven single-site experience built on the Next.js App Router: a full-screen hero with a marquee name slider, scroll-linked parallax project thumbnails with a custom cursor, magnetic buttons, route transitions with a preloader, and Lenis smooth scrolling throughout. Every page experience has one — Home, Work, About, Projects, Achievements and Contact — plus a working contact form that lands straight in my inbox, and a custom 404.

### Key features

- **Hero with marquee slider** — full-screen viewport, oversized moving name, shot with photography and GSAP/Framer Motion easing
- **Parallax project thumbnails** — scroll-linked image slider with hover labels and a custom cursor
- **Magnetic buttons** — buttons that follow the pointer, ghost and accent variants
- **Preloader + route transitions** — word-based preloader and choreographed page transitions on every route
- **Lenis smooth scrolling** — buttery inertia scroll paired with scroll-linked reveals
- **Working contact form** — posts through [Web3Forms](https://web3forms.com) directly to my inbox
- **SEO-ready** — sitemap, robots, Open Graph and Twitter card metadata out of the box
- **Reduced-motion aware** — hero animations degrade gracefully when `prefers-reduced-motion` is set
